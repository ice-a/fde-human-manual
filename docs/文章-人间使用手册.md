# 人间使用手册：把 14 类生活指南整理成一份可查的索引

> 活得明白一点，坑踩得少一点。

网上有很多很好的开源指南：防骗、健康、人情世故、做饭、投资、恋爱、人生进阶……但它们散落在不同仓库和站点里，格式各异，想查一件事，往往要先想起「这事该去哪本找」。

于是做了这个站点：**人间使用手册**。把能收录的内容整理成统一格式，把受限的内容按主题独立改写，再补上几个高频生活主题，做成一份随时可查的索引。

## 它是什么

一句话：**14 册、2374 条、中英双语的生活主题手册**。

它不是成功学，也不是课程。每一条都是可以单独读的内容：一句判断、具体做法、必要的背景，绝大多数条目还带一个真实案例。需要时搜一下、点开看一眼，不需要从头读到尾。

## 内容长什么样

以「防骗与信息安全」为例：每册先有导读精选，下面是按分类分组的全量条目。支持本册搜索、展开/收起全部，条目里只保留文字和必要的案例，不放外链。

![防骗册详情页](https://raw.githubusercontent.com/ice-a/human-manual/main/docs/images/guide-page.png)

一条内容大致是这样：

> **先检索，再转账**
>
> 骗局怕的不是聪明人，是愿意花三分钟核实的人。
>
> - 把对方给的链接、号码、公司名单独搜一遍
> - 换一个渠道向当事人本人确认
> - 凡是「过期不候」的倒计时，默认按骗局处理
>
> 案例：有人接到冒充客服的退款电话，先挂断再打官方客服电话，发现所谓订单根本不存在，避免了转账。

## 不只是内容

站点还做了几个顺手的小东西：

- **一言组件**：右侧卡片每日一句，接口不可用时自动用本地语料兜底。
- **中英双语**：右上角切「简 / EN」，选择保存在浏览器本地。
- **我的站点**：顶部导航集中展示个人主页、博客、图床、短链、动作图鉴等 22 个站点入口，配置来自公开 Gist，改配置不用重新构建。
- **Issue 反馈**：想补充的主题、发现的错误，直接通过页面上的「新建 Issue」提交，步骤和填写模板都写在页面上。
- **自愿赞赏**：关于页折叠放着赞赏码，不赞赏也完全不影响使用。
- **移动端适配**：手机上目录、卡片、折叠条目都能正常阅读。

## 技术上怎么做的

纯静态站点，没有后端和数据库：

- Vite + React + TypeScript
- 内容按册拆成 JSON，进入对应页面时才加载
- `base: './'` + hash 路由，放根目录或子目录都能打开
- GitHub Actions 自动部署到 GitHub Pages，同样支持 Vercel 和 Cloudflare Pages
- 站点清单和反馈文案放在 GitHub Gist，页面运行时读取，本地配置兜底

## 自己部署

Fork 仓库 <https://github.com/ice-a/human-manual> 后：

- **Vercel**：Add New → Project 导入，Framework 选 Vite，直接 Deploy。
- **Cloudflare Pages**：Connect to Git，构建命令 `npm run build`，输出目录 `dist`。
- **GitHub Pages**：Settings → Pages → Source 选 GitHub Actions，仓库已附带 `.github/workflows/deploy.yml`。

本地开发：

```bash
npm install
npm run dev
npm run build
npm run preview
```

## 配置自己的内容

站点清单在 `sites.json`，反馈文案在 `poll.json`，都同步到公开 Gist。直接编辑 Gist 里的 JSON，刷新页面就生效，不用改代码、不用重新构建。

指南正文在 `src/data/content/`，中文源是 `*.zh-CN.json`，英文源是 `*.en.json`。改完内容后运行：

```bash
bun scripts/translate-content.ts
```
