## 🔍 一条内容长这样

以「防骗」册为例，每册先有导读精选，下面是按分类分组的全量条目，支持**本册搜索**和**一键展开全部**。

![防骗册详情页](https://raw.githubusercontent.com/ice-a/human-manual/main/docs/images/guide-page.png)

> **先检索，再转账**
>
> 骗局怕的不是聪明人，是愿意花三分钟核实的人。
>
> - 把对方给的链接、号码、公司名单独搜一遍
> - 换一个渠道向当事人本人确认
> - 凡是「过期不候」的倒计时，默认按骗局处理
>
> 案例：有人接到冒充客服的退款电话，先挂断再打官方客服，发现订单根本不存在，避免了转账。

## 🛠 技术党看这里

纯静态站点，无后端无数据库：

- Vite + React + TypeScript
- 内容按册拆 JSON，进页面才加载
- `base: './'` + hash 路由，放哪都能开
- GitHub Actions 自动部署，Vercel / Cloudflare Pages 也能用
- 站点清单和反馈文案放 Gist，运行时读取 + 本地兜底

## 🚀 想自己搭一个？

Fork 仓库 <https://github.com/ice-a/human-manual>：

- **Vercel**：导入 → Framework 选 Vite → Deploy
- **Cloudflare Pages**：Connect to Git → 构建 `npm run build` → 输出 `dist`
- **GitHub Pages**：Settings → Pages → Source 选 GitHub Actions

本地跑：

```bash
npm install
npm run dev
npm run build
npm run preview
```

改内容：站点清单在 `sites.json`，反馈文案在 `poll.json`，正文在 `src/data/content/`，中改完跑 `bun scripts/translate-content.ts` 生成英文。
